# NovaOS

A calm, modern launcher for the PSP that replaces the XMB. Runs on custom firmware **ARK-4** and **ARK-5**.

## Install

1. Download the zip for your firmware from [Releases](../../releases/latest): `-ark4` or `-ark5`.
2. Unzip it onto the root of your Memory Stick. You get `ms0:/PSP/GAME/NovaOS/EBOOT.PBP`.
3. Start NovaOS from the Game menu.

## Notes

- The ARK-5 build does not load on ARK-4. Pick the one that matches your firmware.
- NovaOS writes only to the Memory Stick, never to `flash0:` or `flash1:`.
